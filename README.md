## 数据集概述

本数据集专注于**田间小麦穗的视觉检测**，服务于小麦表型分析、产量预估及作物管理。数据涵盖不同基因型、生长阶段与成像条件，适配目标检测算法训练、农业AI应用及品种筛选等任务。

## 数据三要素解析

**类别与目标覆盖**
*   数据集定义 **1** 个核心类别：**小麦穗**（wheat_head），聚焦单一目标，便于快速部署与高精度检测。
*   标注框总量达 **188500** 个，图像总量 **4948** 张，平均每张图像约含 **38** 个目标，属于**密集目标检测**场景。
*   每张 1024×1024 切块通常包含约 **20 至 60** 个麦穗，仅少数麦穗跨越切块边界。
![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/baeca2aa305d49329749271b336169b6.png)

**数据规模与采集**
*   图像覆盖 **44 个独立测量会话**，使用多种地面表型平台和相机，拍摄高度 1.8 至 3 米。
*   地面采样距离（GSD）范围 **0.10 至 0.62 mm**，视野角度多样，图像呈现自然变异。
*   部分麦穗因叶片遮挡或相互重叠，仅当至少一个小穗可见时才标注；边缘裁切的麦穗仅当基部可见超过 **30%** 时标注。

**格式与结构**
*   原始标注存储于 CSV 文件（`image_name, BoxesString, domain`），边界框为绝对像素坐标 `x1 y1 x2 y2`。
*   社区提供 **YOLO 格式**转换版本（`class x_center y_center width height`，归一化），可直接用于 YOLOv5、YOLOv8 等框架训练。
*   约 **2%** 的图像无标注（`no_box`），在 YOLO 版本中保留为空标签文件。

## 知识普及：小麦穗检测的技术挑战

*   **密集与重叠**：田间小麦穗密度高，相互遮挡严重，对模型的密集目标分离能力要求较高。建议采用多尺度特征融合或 NMS 参数调优。
*   **生长阶段差异**：从抽穗初期到成熟期，麦穗形态、颜色变化显著。数据集的多样化生长阶段覆盖有助于提升模型鲁棒性。
*   **成像条件变化**：不同相机、光照、拍摄角度导致目标尺度与外观差异大。数据集通过多多平台采集来覆盖这些变异。
*   **标注一致性**：约 **20** 人参与标注与审核，对遮挡、边缘目标有明确标注规则，确保标注质量。


## 快速开始（代码示例）

**1. 准备配置文件 (`data.yaml`)**
```yaml
train: ./dataset/images/train
val: ./dataset/images/val
test: ./dataset/images/test
nc: 1
names: ['小麦穗']
```

**2. 启动 YOLOv8 训练**
```python
from ultralytics import YOLO

model = YOLO('yolov8m.pt')
model.train(
    data='data.yaml',
    epochs=100,
    imgsz=1024,
    batch=8,
    device=0
)
```
